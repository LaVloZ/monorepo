# coffee-kata

Coffee Machine kata : traduire des commandes de boissons (café, thé, chocolat, orange…) en instructions pour le `DrinkMaker`, avec gestion de l'argent, des options (extra hot, sucre/touillette), du reporting des ventes et des alertes de stock (`BeverageQuantityChecker`, `EmailNotifier`).

- Java 8, Maven, JUnit 5, Mockito, Hamcrest
- Package `lv.merrill.apprentissage.coffee`

```
mvn test
```
