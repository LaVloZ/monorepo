# nullobject

Petite bibliothèque Java (2017) autour du pattern Null Object : `NullUtils.register(...)` pour déclarer la valeur nulle d'un type, `NullUtils.get(...)` / `Nullifier` pour l'obtenir, `Cache` pour les mémoriser.

- Maven, Mockito, commons-collections4
- Code dans `nullobject/`

```
cd nullobject && mvn test
```
