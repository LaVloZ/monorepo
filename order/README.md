# order

Exercice DDD en Java : deux bounded contexts, `order` (commande, `Money` en value object, calcul du total, invariants sur le statut) et `shipping` (expédition, `Weight`, limite de poids, transit et livraison). Deux `main` de démo : `ECommerceApp` et `ShippingApp`.

Non terminé, sans tests.

- Java 17, Maven
