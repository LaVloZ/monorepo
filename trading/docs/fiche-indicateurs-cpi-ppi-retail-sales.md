# Fiche indicateurs macro US — CPI, PPI, Retail Sales

> Les trois publications mensuelles qui calibrent les attentes sur les taux de la Fed.
> Séquence type chaque mois : CPI (mardi) → PPI (mercredi) → Retail sales (jeudi), toutes à **14h30 heure de Paris** (8h30 ET).

---

## Vocabulaire de base

- **MoM** (*Month over Month*) : variation vs le mois précédent. Réactif mais volatil.
- **YoY** (*Year over Year*) : variation vs le même mois un an avant. Lissé, gomme la saisonnalité — c'est le chiffre des gros titres.
- Lecture combinée : un YoY encore élevé + des MoM faibles plusieurs mois de suite = l'inflation se calme, le YoY suivra mécaniquement.
- **Règle d'or** : ce qui fait bouger les marchés, c'est la **surprise vs consensus** et la **tendance**, pas le chiffre absolu.

---

## 📌 CPI — Consumer Price Index (inflation consommateur)

| | |
|---|---|
| **Mesure** | Prix d'un panier de biens/services payés par les ménages US (logement ~35 %, alimentation, énergie, transport, santé…) |
| **Source** | Bureau of Labor Statistics (BLS) |
| **Calendrier** | 1×/mois, vers le 10-15 du mois (pour le mois précédent), 14h30 Paris |
| **Impact marché** | 🔴 Le plus market-moving des trois |

**Versions** : *headline* (tout inclus) et *core* (hors énergie/alimentation — plus stable, plus suivi par la Fed).

**Interprétation** :
- La Fed vise ~2 % (officiellement sur le PCE, mais le CPI est le chiffre que tradent les marchés).
- CPI qui décélère → espoir de baisse de taux → positif actions / crypto / or.
- CPI qui accélère → Fed dure plus longtemps → négatif actifs risqués.
- Trop bas / négatif (déflation) → signal de récession → négatif aussi, pour d'autres raisons.

---

## 📌 PPI — Producer Price Index (inflation producteur)

| | |
|---|---|
| **Mesure** | Prix facturés par les producteurs en sortie d'usine (matières premières, biens intermédiaires, services B2B) — l'inflation **en amont** de la chaîne |
| **Source** | Bureau of Labor Statistics (BLS) |
| **Calendrier** | 1×/mois, généralement le lendemain du CPI, 14h30 Paris |
| **Impact marché** | 🟡 Moyen, sauf grosse surprise — affine la lecture du CPI de la veille |

**Interprétation** :
- **Indicateur avancé** : un PPI qui monte annonce souvent un CPI qui montera quelques mois plus tard (répercussion des coûts sur les prix de vente).
- **Lecture marges** : PPI > CPI = les entreprises absorbent les coûts → marges comprimées → négatif profits. PPI < CPI = marges qui respirent.

---

## 📌 Retail Sales — Ventes au détail

| | |
|---|---|
| **Mesure** | Chiffre d'affaires total des commerces US (magasins, e-commerce, restaurants, essence). Thermomètre du consommateur (~70 % du PIB américain) |
| **Source** | Census Bureau |
| **Calendrier** | 1×/mois, vers le 15-17 (juste après CPI/PPI), 14h30 Paris. Exprimé en MoM |
| **Impact marché** | 🟡 à 🔴 selon le contexte (élevé quand la Fed est en balance) |

**Versions** : total, *core* (hors autos), *control group* (hors autos/essence/matériaux — entre directement dans le calcul du PIB).

**Interprétation — à double lecture selon le régime** :
- Économie saine + inflation calme : chiffre fort = bon (profits, croissance).
- Régime inflationniste avec Fed hawkish : chiffre **trop fort** = mal reçu (conso qui alimente l'inflation → arguments pour une hausse de taux) ; chiffre modéré = idéal (« goldilocks ») ; chiffre très faible = crainte de récession.

---

## Lecture d'ensemble du trio

Les trois ensemble répondent à trois questions complémentaires :

1. **CPI** — les prix payés par les ménages ralentissent-ils ?
2. **PPI** — les coûts en amont (et donc l'inflation future + les marges) se calment-ils ?
3. **Retail sales** — le consommateur tient-il le coup ?

C'est cette photo complète qui calibre les attentes de taux (FOMC) et donc la direction des actions, de la crypto, de l'or et du dollar.
